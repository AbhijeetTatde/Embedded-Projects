# Line Following Robot using STM32 Blue Pill

An autonomous embedded robotics project developed using the STM32F103C8T6 (Blue Pill) ARM Cortex-M3 microcontroller. The robot follows a predefined path using IR sensors and performs real-time motor control using PWM-based speed regulation and interrupt-driven sensor processing.

The project focuses on low-level embedded firmware development, realtime response handling, motor driver interfacing, GPIO configuration, timer-based PWM generation, and external interrupt management using STM32 HAL drivers in STM32CubeIDE.

---

# Project Objectives

- Develop a realtime autonomous line-following robot
- Implement PWM-based DC motor control using STM32 timers
- Perform interrupt-driven sensor detection for faster response
- Reduce oscillations and unstable movement using speed tuning
- Build embedded firmware using STM32 HAL drivers
- Gain hands-on experience with ARM Cortex-M microcontrollers

# Working Principle

The robot continuously monitors the surface using IR sensors to detect the black path line. Based on sensor input states, the firmware dynamically adjusts motor speed and direction.

## Logic

| Left Sensor | Right Sensor | Robot Action |
|---|---|---|
| White | White | Move Forward |
| Black | White | Turn Left |
| White | Black | Turn Right |
| Black | Black | Stop |

Motor movement is controlled using PWM signals generated by TIM1 channels. Sensor state changes are captured using EXTI interrupts for faster response and reduced polling overhead.

---

# PWM Motor Control

PWM (Pulse Width Modulation) was implemented using TIM1 peripheral to control motor speed dynamically.

## Timer Configuration

| Parameter | Value |
|---|---|
| Timer | TIM1 |
| Prescaler | 71 |
| Counter Period | 999 |
| PWM Frequency | ~1 KHz |

Different PWM duty cycles were applied to left and right motors during turning operations to reduce overshoot and oscillation.

Example:
- Left turn -> Left motor slow, right motor fast
- Right turn -> Right motor slow, left motor fast

This improved path correction smoothness significantly.

---

# Interrupt-Driven Execution

External interrupts (EXTI) were configured for IR sensors to improve realtime responsiveness.

## Benefits

- Faster line detection
- Reduced CPU polling overhead
- Immediate correction response
- Better tracking stability
- Lower latency compared to delay-based systems

Interrupts used:
- EXTI0 -> PA0
- EXTI1 -> PA1
